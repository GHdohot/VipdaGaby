    O que este painel guarda

    Eventos de funil, país selecionado/estimado, idioma, categorias gerais de dispositivo e navegador, domínio de referência, UTMs e pedidos de pagamento. Eventos analíticos são removidos após 90 dias. Não guardamos IP, GPS, fingerprint, nome, e-mail ou o texto completo de páginas de referência.

    —Dados de navegação são registrados para análise da operação; pagamentos são registrados para operar pedidos.
